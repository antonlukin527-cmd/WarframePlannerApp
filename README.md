# 🛠️ Warframe Build Planner PRO

**Warframe Build Planner PRO** — это фанатский веб-инструмент для создания, анализа и оптимизации билдов в игре Warframe. Проект написан на чистом HTML, CSS и JavaScript (Vanilla JS) и не требует сложной серверной части.

## ✨ Основные возможности

*   **Динамический Калькулятор Урона:** Точный расчет урона, ДПС и времени убийства (TTK) с учетом базовых статов оружия, модов, тиров крита, статусов и уязвимостей врагов.
*   **Система Вместимости (Capacity & Forma):** Умный подсчет очков вместимости с учетом установленных полярностей. Если полярность мода совпадает со слотом, стоимость делится на 2.
*   **База Мета-Билдов:** Интеграция готовых шаблонов билдов от известного билдостроителя **ninjase** (с платформы Overframe). Автоматическая подстановка модов, аркан, осколков и питомцев.
*   **Моды Разлома (Ривейны):** Конструктор идеального Ривейна (3 позитива + 1 негатив) с анализом базовых статов оружия.
*   **Продвинутый UI/UX:** Темная/светлая тема, настраиваемая палитра цветов (как в WFHelper), Drag & Drop для модов, красивые дашборды с результатами расчетов.
*   **Дополнительные Инструменты:** Справочник способностей Хелминта, трекер эволюций Инкарнона, конструктор Зо/Китганов, планировщик реликвий и интеграция с `warframe.market` для подсчета стоимости сборки.

## 🗂️ Структура проекта

*   `builds.html` — главный интерфейс приложения (все вкладки).
*   `css/style.css` — стили приложения, темы и адаптивная верстка.
*   `js/` — вся логика приложения:
    *   `calc.js` — ядро калькулятора урона.
    *   `capacity.js` — логика полярностей и вместимости.
    *   `optimizer.js` — умный авто-подбор модов.
    *   `market.js` — интеграция с торговой площадкой.
    *   и другие вспомогательные скрипты.
*   `js/data/templates/` — JSON-файлы с готовыми билдами (Saryn, Nidus, Dante и др.).
*   `*_data.js` (в корне) — базы данных WFCD (моды, оружие, варфреймы).

## 🚀 Как запустить

Проект не требует сборки (Webpack/Vite) или установки `node_modules` для работы фронтенда.
1. Скачай репозиторий.
2. Открой файл `builds.html` в любом современном браузере (Chrome, Firefox, Edge).
3. Или запусти локальный сервер (например, через расширение *Live Server* в VS Code).
